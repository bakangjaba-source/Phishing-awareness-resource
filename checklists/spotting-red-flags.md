# Phishing Red Flags Checklist

## Sender
- [ ] Does the display name match the actual email address header?
- [ ] Are there typos in the domain name (e.g., microsft.com instead of microsoft.com)?
- [ ] Have you received unexpected emails from this sender before?

## Message wording
- [ ] Does the message create a false sense of urgency or panic (e.g., "Account suspended in 24 hours")?
- [ ] Are there spelling, grammatical or awkward phrasing errors uncharacteristic of the sender?
- [ ] Is the greeting generic (e.g., "Dear Customer") instead of addressing you by name?

## Links and attachments
- [ ] Do URLs preview to unfamiliar, strange, or mismatched domains when you hover over them?
- [ ] Did you verify the link destination independently rather than clicking directly from the message?
- [ ] Are there suspicious file attachments (like .zip, .exe or .iso)?
   
## Requests for information or money
- [ ] Does the message ask for sensitive credentials, passwords or One-Time Passcodes (OTPs)?
- [ ] Have you independently confirmed the request from a trusted or known phone number?
